# Shell 接入示例

[English](README.md)

`shell-integration.json` 展示包含可选显示面板和免密锁屏的组合安装。推荐生效默认值由 [推荐预设](../../profiles/recommended.json) 定义。

字段描述状态栏组件替换、服务、禁用插件 ID、克隆恢复元数据和置顶托盘项。安装器通过 Omarchy CLI 启用插件，运行中的 Shell 读取用户的 `~/.config/omarchy/shell.json`。

支持的生效命令见 [安装说明](../installation.zh-CN.md) 和各功能 README。此 JSON 示例用于说明字段之间的关系。
