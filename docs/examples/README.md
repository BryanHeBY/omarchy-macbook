# Shell integration example

`shell-integration.json` illustrates a combined installation including optional
display controls and passwordless locking. Recommended activation defaults are
defined in [the recommended profile](../../profiles/recommended.json).

The fields describe widget replacements, services, disabled plugin IDs, clone
restore metadata and pinned tray items. The installer activates plugins through
Omarchy's CLI. The running shell reads the user's
`~/.config/omarchy/shell.json`.

Use the [installation guide](../installation.md) and feature READMEs for supported
activation commands. This JSON file is an example for understanding the field
relationships.
