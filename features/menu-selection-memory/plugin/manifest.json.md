# manifest.json

> **Optimized for Omarchy M (MacBook).** Part of a configuration and plugin
> collection that brings familiar macOS workflows and a desktop experience
> closer to native macOS.

The `menu-selection-memory` manifest declares the display name, version,
capabilities and entry points. The plugin remembers the last selected result for
each menu and search query.

`clonedFrom` points to `omarchy.menu` for Omarchy plugin replacement and built-in
route resolution. This companion file documents the strict JSON manifest.
